# Web Designs

A collection of standalone web design projects. Each project lives in its
own top-level folder with its own README.

## Projects

- [`aura-product-showcase/`](./aura-product-showcase) — AURA, a motion-driven
  product studio showcase inspired by [motion.zajno.com](https://motion.zajno.com/):
  dark theme, kinetic typography, custom cursor, scroll-triggered reveals
  and parallax. Plain HTML/CSS/JS, no build step.
- [`logistics-freight-hero/`](./logistics-freight-hero) — Freightline, a small
  logistics/freight site. Opens on a full-viewport pixel-precise hero (aerial
  freight-train video, mirrored overlay type, one entrance animation), then
  scrolls into a parallax, scroll-reveal "story" homepage with a second video
  section, plus services, about and contact pages, a shipment-tracking flow
  and a 4-step get-a-quote wizard. Plain HTML/CSS/JS, no build step.
